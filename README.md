## The entry

> Out of office: this plant is on strike. No water since March, no sunlight, and HR still calls me 'low maintenance'.

(115 characters.)

## Run

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt`. Stdlib only, deterministic — the same bytes on every run.
